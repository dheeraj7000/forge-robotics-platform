Robotics Reliability & Deployment Platform

A robotics reliability platform for developing, evaluating, debugging, and deploying ML-powered robotic systems. What happens after a model or robot policy leaves the notebook?

System Architecture

How a task flows through the Forge pipeline.

  Task YAML + Fault Profile
        │
        ▼
  ┌───────────┐     ┌──────────┐
  │  Runner    │────▶│ Recorder │──▶ runs/run_XXXXX/
  │            │     └──────────┘      metadata.json
  │ load       │                       trajectory.npz
  │ reset      │     ┌──────────┐      config.yaml
  │ inject     │────▶│ Faults   │      result.json
  │ loop:      │     └──────────┘
  │  policy    │
  │  sim.step  │     ┌──────────┐
  │ evaluate   │────▶│Evaluator │──▶ EvalResult
  └─────┬──────┘     └──────────┘
        │
        ▼
  ForgeSimulation (MuJoCo)
  ┌─────────────────────────────┐
  │ Menagerie Panda + Table     │
  │ + Objects (freejoint)       │
  │                             │
  │ step / reset / query state  │
  └─────────────────────────────┘

The Runner orchestrates the full lifecycle: load scenario, reset simulation, inject faults, run the policy loop, and evaluate results. Recorded runs capture every joint state, action, and evaluation result for replay and regression testing.

Quick Start

Get up and running in minutes. No ROS required.

Install

bash
pip install mujoco mujoco_menagerie numpy PyYAML opencv-python-headless pytest
pip install -e '.[ml]'  # PyTorch for learned policies (optional)

Run Tests

bash
python3 -m pytest tests/ -v

384 tests, no ROS needed

Evaluate a Task

bash
python3 scripts/forge_eval.py --task pick_red_cube

Train a Policy

bash
python3 scripts/forge_train.py --task pick_red_cube --episodes 5

Deploy to Edge

bash
python3 scripts/forge_deploy.py --export --model models/bc_policy.pt --output models/bc_policy.onnx

CLI Tools

A dedicated CLI for every stage of the robotics workflow.

forge_eval

Task evaluation

python3 scripts/forge_eval.py --task pick_red_cube
python3 scripts/forge_eval.py --suite manipulation-v1

forge_chaos

Chaos testing

python3 scripts/forge_chaos.py --task pick_red_cube --fault object_moved
python3 scripts/forge_chaos.py --task pick_red_cube --fault cascading --compare

forge_perception

Perception pipeline

python3 scripts/forge_perception.py --scenario basic_workspace --detect --annotate -o detections.png

forge_train

ML training

python3 scripts/forge_train.py --task pick_red_cube --episodes 5
python3 scripts/forge_train.py --list-models

forge_registry

Experiment & model registry

python3 scripts/forge_registry.py experiments list
python3 scripts/forge_registry.py models promote bc_pick_red_cube --version 1 --stage validated

forge_regression

Regression testing

python3 scripts/forge_regression.py --check --suite manipulation-v1
python3 scripts/forge_regression.py --create-baseline --suite manipulation-v1

forge_deploy

Edge deployment

python3 scripts/forge_deploy.py --export --model models/bc_policy.pt --output models/bc_policy.onnx
python3 scripts/forge_deploy.py --benchmark --model models/bc_policy.onnx

forge_fleet

Fleet & OTA management

python3 scripts/forge_fleet.py devices register --id arm-01 --name "Panda Arm 01" --type panda
python3 scripts/forge_fleet.py ota deploy --package-id pkg_00001 --target-group production

forge_robot

Physical robot

python3 scripts/forge_robot.py connect --type simulated --scenario basic_workspace
python3 scripts/forge_robot.py safety-check

forge_doctor

Health check

python3 scripts/forge_doctor.py

forge_replay

Run replay

python3 scripts/forge_replay.py --list
python3 scripts/forge_replay.py runs/run_00001/ --step 50
